# 成都麻将缺一门计分

仓库地址：[https://github.com/kevin-chen-2022/mahjong-queyimen-score](https://github.com/kevin-chen-2022/mahjong-queyimen-score)

方便麻友快速算分记账。

工具采取三标签页布局，明暗两种风格转换。具体说明请点击页面标题栏右侧的"帮助"按钮。

## 计分

可根据胡牌顺序拖拽玩家方格重新排列。长按方格右侧的得分详情可显示"得分信息输入卡片"。

## 历史

浏览历史牌局的得分情况，也可在此手动输入玩家得分。

可在此设置玩家起始资产、加番情况以及牌型计分，提供编辑（增加、删除、修改、排序）和浏览功能。
